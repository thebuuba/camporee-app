# Camporee

PWA para organizar un camporee antes, durante y después del evento.

## Stack
- Next.js + TypeScript
- Supabase (Auth, PostgreSQL, Storage)
- Cloudflare para despliegue

## Módulos iniciales
Inicio, tareas, programa, listas, comidas, participantes, gastos, apuntes e inventario.

## Variables
Copia `.env.example` a `.env.local` y configura `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.

Nunca agregues claves secretas o `service_role` al repositorio.
